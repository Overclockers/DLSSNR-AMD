## 推荐与核心问题

优先查清 EXP-029 的正确性失败，再判断是否存在可保持数值的偏置加载调度机会。
实验问题是：**把 attention 的不可变 FP32 bias 提前到 QK WMMA 前，为什么改变输出？
变化来自片段存储形式、加载移动，还是最终算术/数据流变化？**

这是有明确历史失败输入的因果诊断，目标首先是关闭证据缺口。
不是重新跑旧候选的性能，也不是承诺该方向具有最大的毫秒收益。
如果无法解释正确性失败，本项以诊断未解决结束，不靠放宽精度继续。

## 一个实验、三个固定对照

首先在隔离快照中复现旧版本 A/C 的正确性差异，核对原 SPIR-V、配方和模型身份。
旧候选 SPIR-V 为 `306ee32679939eee3c5286d52a03643dce09593a034f0d6f4af8c23394fab9f6`，
旧基线为 `ec8a83af07742e3049a8318a2fd651ea50daee446ab43d3c2aa2f07c24962122`。
旧二进制只作故障复现，不作为当前生产性能基线。

| 对照 | 改动 | 要区分的机制 |
| --- | --- | --- |
| A | 原路径：QK 完成后，每个 j 读取 bias 并立即消费 | 独立数值基线 |
| B | 在原来的每个 j 读取位置写入 `prefetched_bias[j]`，再立即读出消费；不提前加载 | 引入片段数组/复制本身是否改变代码或输出 |
| C | 保持 B 的片段类型、地址及消费表达式，把四个读取移到当前 query 的 QK WMMA 前 | 在数组表示基础上，延长存活期和改变调度的影响 |

B/C 是归因用控制，不开展多个预取深度、布局或线程划分搜索。
B 若被编译器完全折叠回 A，保留这个结果，它说明该控制在最终代码层未产生变化。
C 相对 A 同时改变了存活期和调度，不能仅凭三组输出就归咎于某个驱动缺陷。

## 定位步骤

1. 核对原始 GLSL、宿主配方、预处理/四元素改写/展开后的 GLSL、SPIR-V 与 driver ISA。
   检查每个 m/j/head 的地址、ColumnMajor 片段方向、有效窗口 guard、数组作用域及初始化。
2. 在完整失败重现后，逐次缩小到第一个发生差异的 C256 DS 调用和窗口。
   优先复用现有中间值回读工具；不要一次添加所有阶段日志。
3. 依次比较真实输入下的 bias 原始 FP32 位模式、QK 累加值、bias 融合/缩放结果、
   half 指数结果及概率输出。追踪第一处差异，而不是只看最终图像。
4. 对应检查 ISA 中的地址、寄存器定义/使用、MMA 操作数、FMA 修饰和转换边界。
   原 EXP-028 的 `0x30208` / `0x31268` 仅用于旧产物定位；当前产物必须重新对应。
5. 如果缩小 shader 或加入回读后失败消失，记录诊断扰动并返回失败版本做静态比对；
   不把最小程序通过当作原问题已经解决。诊断程序只验证数值，不报告性能。

不预设是实现错误、展开器问题或驱动问题。对驱动缺陷的判断需要保留可复现失败样本及编译证据。

## 转入优化的条件

只有找到并验证具体根因，才在继承 EXP-088 的当前基线上准备一个有依据的修正版。
如果根因表明移动不可保持原语义，或没有可接受的修复，本项就此结束。
修正版仍只修改 `g_fswinpds256` 对应的 Windows shader。

- 模型、FP32 bias、MMA 及归约顺序、转换/舍入、有效窗口、同步和任务数保持。
- 禁用改动时恢复各自独立基线；主仓和宿主配方分别核验，不能互相冒充。
- 检查加载是否真的提前、到消费者之间是否增加独立工作，记录资源和实际 scratch。
- 新增 scratch、输出不一致或没有实现预期调度变化时，不进入完整性能验收。
- 静态 VGPR 数量不直接当作 occupancy 或性能结论，不要求机械复现旧版 229 的数字。

## 性能、正确性与停止条件

环境沿用 RX 9070 XT、2258×1270 输入、2368×1280 工作尺寸、单遍、100% 尺度、
R11G11B10 完整宿主 NR、depth=3；新执行前重新核对驱动和实际 dispatch/资源身份。
静态无历史性能负载与历史正确性验收分开；真实游戏仍暂缓。

性能复用 EXP-080 协议：每轮前基线统一预热 4000 帧，正式调用预热 100/测量 200；
初测 ABBA×3、同路径控制×2，最多一次 BAAB×3 反序确认及对应控制。
这里 A/B 指基线与唯一修正版，与上面的三个数值诊断对照分开。
以 D3D12 输入复制到输出复制的完整 GPU 区间验收，保留逐内核辅助数据。
全程保留所有批次，记录时钟/温度的采样范围，不把未对齐遥测当作固定时钟证据。

保留要求是精确输出通过、初测/反序收益一致且可区别于同期同路径波动。
再覆盖中间值、非整齐尺寸、边缘、格式、历史、replay、fallback 和两仓实际产物；
仅静态照片通过不足以集成。最终小于控制波动则记为 unproven，不追加更多确认挑结果。

无论是否加速，交付应包含：A/B/C 数值结果、首次差异位置及根因证据（或明确未解决）、
实际机器码变化、唯一候选的性能结论（或未进入原因）。
本设计不设可节省百分比；43.68% 不能用于估算整网收益。
