# EXP-003：Windows C32、前馈访存与输入层特化探索

日期：2026-10-06。结论：**本轮未保留生产改动**。20 组候选完成 GPU 筛选，
进入整网复测的方案未建立可靠收益；当前产品仍使用 EXP-002 的已验证实现。

## 范围与身份

- 主仓基线 `a6829dd`，宿主基线 `38ea72c`；生产源代码及宿主资产未修改。
- 沿用 EXP-002 的 RX 9070 XT / Windows 驱动 `32.0.31041.1004`、MSVC 14.51.36231、glslang 16.5.0。
- 以宿主已验证完整着色器的独立副本为基线，保留其循环展开和 ViT 尾块补丁。
  先重建五个 C32/输入输出内核，SPIR-V 与保存基线逐字节相同。
- 所有原型位于忽略的 `build/windows/exp003/`；没有把未采用的宏或 shader 算术变更放进生产树。
  原型补丁 SHA-256：`8773495d20c73cc4cbcac76b6e765de0f1aa64a91630c3c0ab2de52204ddc104`。
- 使用 EXP-002 的最终普通基准程序：SHA-256
  `cf572341bee089cffa83ad090ca531f2bf22a0e0b24d55441c31cd44928ae5d5`。
  另行构建当前源码的 `--pipeline-stats` 版本，仅用于寄存器与 ISA 诊断。

## 输入与测量

源 2258×1270、原生工作尺寸 2368×1280、ViT 800 tokens，arena reuse，FP32 输入/输出，
100% 模型尺度、单次 NR。输入沿用 EXP-001 的重采样验证照片，默认控制参数，无时间历史、SR、FG 或游戏负载。
运行前和诊断阶段均未发现 `yysls.exe`；没有采样 GPU 频率、温度或其他程序的 GPU 使用率。

共 62 次基准调用：30 次逐层筛选、28 次无逐层插桩的整网比较、4 次驱动统计诊断。
性能调用每轮 100 帧预热、200 帧测量；统计调用仅 3 帧预热、5 帧测量，**不作为性能结果**。
每个数值是该轮 200 帧的 GPU 平均耗时，不是中位数。不同批次的绝对时间有漂移，不能跨批次相减。

```powershell
<benchmark> 2258 1270 <plan> --reuse --model-pack <private-model> --spv-dir <baseline-or-candidate> --pipeline-cache <cache> --in-image <photo-rgba32f> --out-image <output> --warmup 100 --repeats 200
```

筛选时追加 `--per-layer`；最后两组整网比较均移除它。基线已经包含 EXP-001 和 EXP-002，
这里没有重新宣称此前的收益。

## 假设与筛选结果

C32 普通层约占 1.2 ms，输入和输出层各约 0.9 ms；C32 普通内核使用 189 VGPR。
先测试减少地址计算、LDS 交换和中间值存活范围，再测试 C512 前馈层的读取方式与驻留数量。
保持现有精度、量化边界和每个结果的累加次序；未评估任何有损策略。

下表为早期逐层筛选，局部数字仅用于说明取舍。单次整网最快值不作为提速结论。

| 方向 / 配置 | 观测与处置 |
| --- | --- |
| C32 `NR_WAVE_UNIFORM=1` | 普通层 1.216 ms，邻近基线 1.223 ms；上采样差异也很小，未建立明确收益 |
| C32 单 wave 的 K 保留寄存器 | 普通层 1.223 ms，上/下采样约 0.244/0.238 ms；基本持平 |
| C32 V 改为 LDS 路径 | 普通层 1.237 ms，上采样约 0.244 → 0.292 ms；排除 |
| C32 `NR_CVT4_SPLIT=3` | 普通层 1.243 ms，上/下采样也略慢；排除 |
| attention 按查询块完成 softmax | 普通层约 1.228 ms；中间值范围缩小，但寄存器和访存结果不足以带来收益，见下表 |
| 查询块调整叠加 K 寄存器 | 普通层约 1.222 ms；未改善整体，排除 |
| 前馈权重改为 16 字节整数视图 | 保持 FP8 字节，局部约 0.537 ms，邻近基线约 0.479 ms；变慢 |
| 前馈激活改为 8 字节整数视图 | 局部约 0.457 ms，但基线本身曾在 0.439..0.537 ms 间波动；未确立收益 |
| 权重与激活整数视图一起用 | 局部约 0.562 ms；排除 |
| 前馈标量化 wave 地址 | 局部约 0.467 ms；未确立整网收益 |
| 前馈增加 LDS 驻留限制 | 8192/12288/16384/21504/32768 字节；21504 最值得复测，但整网复测与基线持平 |
| C32 Horner 操作数模式 3/5/7 | 普通层分别约 1.223/1.243/1.239 ms；变化有限，未保留 |
| pre `NR_PRE_FULL=71` | pre 约 0.897 → 0.879 ms；去除完整窗口的冗余范围判断，同时保留半精度舍入所需分支；最后整网复测未复现收益 |
| pre 特化 + 前馈 LDS 21504 | 四轮平均看似快 0.064 ms，但该组同时出现约 0.2 ms 的时序波动，单项收益也未通过复测；不保留 |

20 组配置包含上表分组中的多个取值及组合。另一个 pre 四-wave 设想在编译时被现有形状约束拒绝，
没有上 GPU，也没有修改该约束绕过检查。

## 驱动统计解释

来自同一当前源码的诊断构建；静态指令行数不是动态执行次数或耗时。
列出的内核均未使用 scratch。

| 方案 / 内核 | VGPR | LDS 字节 | 静态指令行数 | 含义 |
| --- | --- | --- | --- | --- |
| 基线 `fswin32` | 189 | 2048 | 4867 | C32 对照 |
| 查询块顺序 `fswin32` | 185 | 2048 | 4897 | VGPR 只降 4；静态 LDS load 从 4 增到 16，等待指令也增加 |
| 基线 / 查询块顺序 pre | 124 / 137 | 6144 / 6144 | — | 输入层的寄存器反而增加 |
| 基线 / 查询块顺序 post | 122 / 126 | 4096 / 4096 | — | 输出层也增加 |
| 基线 pre | 124 | 6144 | 3509 | 完整窗口特化对照 |
| pre 特化 71 | 124 | 6144 | 3240 | 主要减少标量分支；WMMA、转换和 clamp 指令数量不变 |
| 基线 `ffwd3w` | 182 | 0 | 4185 | 前馈对照 |
| LDS 21504 `ffwd3w` | 216 | 21504 | 4150 | 限制驻留还改变了驱动分配；不能只凭更少同时驻留的工作组推断更快 |

## 无逐层插桩的整网复测

第一批四轮每轮比较四个配置，奇数轮按表头顺序，偶数轮反序：

| 轮次 | 基线 ms | pre 特化 ms | 前馈 LDS 21504 ms | 两者组合 ms |
| --- | --- | --- | --- | --- |
| 1 | 10.674 | 10.687 | 10.681 | 10.672 |
| 2 | 10.714 | 10.674 | 10.697 | 10.685 |
| 3 | 10.822 | 10.763 | 10.834 | 10.618 |
| 4 | 10.566 | 10.555 | 10.567 | 10.545 |
| 均值 | 10.694 | 10.670 | 10.695 | 10.630 |

前馈驻留限制没有整网收益。第 3 轮后半段绝对时间明显下降，后续第 4 轮也整体较低；
未采样频率和温度，无法准确归因，不能将该下降算给组合方案。

第二批只比较 pre 特化与基线，六对交替 A→B / B→A：

| 对次 | 基线 ms | pre 特化 ms | 节省 ms |
| --- | --- | --- | --- |
| 1 | 10.393 | 10.459 | -0.066 |
| 2 | 10.452 | 10.422 | 0.030 |
| 3 | 10.471 | 10.488 | -0.017 |
| 4 | 10.501 | 10.470 | 0.031 |
| 5 | 10.512 | 10.514 | -0.002 |
| 6 | 10.523 | 10.504 | 0.019 |
| 均值 | **10.475333** | **10.476167** | **-0.000833** |

三对快、三对慢，方向随运行先后改变；平均约 0.001 ms 的差异不支持性能提升。
这是未复现可靠收益，不是证明该特化在所有负载、尺寸或驱动上永远无效。

## 下一轮条件

不要在同样条件下继续盲扫这些 wave、LDS 和排列参数。当前 C32 ISA 中 clamp、格式转换和
相关调度指令仍占明显部分，但静态计数不能证明它们是全部瓶颈。
下一轮先围绕具体转换链建立小型 GPU 对照，检验是否能改变指令生成而保留每个舍入、饱和和非有限值语义；
只有机制成立且整网重复测量有收益，再扩大到控制、边缘和历史验证。已有的饱和转换失败原型仍以 EXP-002 为排除依据。
