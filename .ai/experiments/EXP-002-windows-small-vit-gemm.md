## 假设与实现

2258×1270 对应 2368×1280 工作尺寸、ViT 的 800 tokens。
原 `gemmprojw` 每工作组只有两个 wave，每 wave 计算 64×64；Windows 驱动使用 166 VGPR。
新增 `gemmprojws` 保持工作组输出 **64×128**，改为八个 wave、各计算 32×32，VGPR 降至 **70**。
两者 LDS 和 scratch 均为零。FP8 输入、FP32 累加、每个输出的 K 累加顺序及权重格式不变。

- 原 recipe：`WM=1 WN=2 MFRAG=4 NFRAG=4 KFRAG=8`。
- 新 recipe：`WM=2 WN=4 MFRAG=2 NFRAG=2 KFRAG=8`。
- 只在原本选择宽 ViT 收缩、工作组为 64×128、`768 <= M <= 1024` 时选择新内核。
- 原生 4K NR 的 2160 tokens 上，新分工反而使该组内核约 0.725 → 0.937 ms（单对筛选）；较大输入继续使用原内核。
- 将新内核加入 N-pair 权重打包；host define、manifest 值及严格解析器同步增加 `projws_max_tokens=1024`。
- `--no-projws` 只供离线 A/B，恢复原内核选择。本次没有有损策略或画质降级开关。
- Linux 未改动；本次保留变更没有修改着色器算术源码。

新增 SPIR-V SHA-256：`e0c3e40657cb29894195d127fccd9df6e5d03507881f216e804c31e96ae60143`。

## 测量与复现

FP32 输入/输出、100% 模型分辨率、单次网络、arena reuse；源为 EXP-001 的重采样仓库验证图。
同一个最终基准程序、同一套完整着色器、同一 pipeline cache，用 `--no-projws` 比较原路径。
每轮 100 帧预热、200 帧测量；六对测试交替采用 A→B、B→A，最后性能不启用逐层计时。
没有 SR、FG、游戏负载或 D3D12 搬运；时钟和温度未采样，期间绝对时间有缓慢漂移。
每轮数值是 200 帧的 GPU 平均耗时，不是单帧中位数。各对均显示收益，但不宣称跨会话统计显著性。

构建步骤见 [BENCHMARK.md](../../windows/build/BENCHMARK.md)；在宿主 x64 MSVC 环境中运行
`python tools/build/build-mochizuki-runtime.py exports/mochizuki-gemm-small`，取得保留宿主补丁的配套着色器。

```powershell
<benchmark> 2258 1270 <plan> --reuse --model-pack <private-model> --spv-dir <matching-host-shaders> --pipeline-cache <cache> --in-image <rgba32f-image> --out-image <output> --warmup 100 --repeats 200
```

## 未保留的探索

下表为早期逐层筛选，单次整网时间受其他内核波动影响，不按全网孤立最快值排序。

| 方向 | 观测与处置 |
| --- | --- |
| 输入特征半精度写入打包 | 0.885 → 0.886 ms，字节一致，无收益 |
| C32 饱和转换改写 | 整网 12.296 ms，输出变化；排除 |
| C128 QK/V 调度 fence | 整网约 10.675 ms，目标段基本持平；排除 |
| C32 普通层改为两 wave | 该组约 1.21 → 1.24 ms；排除 |
| GEMM 跨 chunk 预取 | 收缩约 0.64 → 0.70 ms，其他两段也未改善；排除 |
| C128 去除 straggler 队列 | 目标段仅约 0.005..0.010 ms 小幅差异；未保留 |
| 收缩 KFRAG=16 | 约 0.645 ms，无收益 |
| C32 流式 MLP，补足 FP32 残差 | 输出一致；只有 post 约省 0.012 ms，其他层抵消；不纳入 |
| pre 完整窗口特化 71 | 输出一致，pre 约省 0.020 ms；独立候选，未纳入本次默认更改 |
| post 改回 LDS 投影 | 约 0.886 → 0.924 ms，输出变化；排除 |
| 收缩只拆 M / 只拆 N | 分别约 0.61 / 0.75 ms；仅两轴一起拆分达到约 0.37 ms |
| ViT expand/QKV 也拆两轴 | 仅约 0.004/0.010 ms 小幅差异；未保留 |
| ViT expand/QKV 只拆 M | 两段均变慢；排除 |
