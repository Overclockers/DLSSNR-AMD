# EXP-010：C512 attention 偏置读取布局

日期：2026-10-07（Asia/Hong_Kong）。结论：**两种布局均未建立稳定总路径收益，不保留。**
无人值守运行 `20261006-235052-9070xt` 第 3/10 个假设；两个变体，用完一次追加确认测量。

## 假设与实现

本次从当前主仓重新构建 C++17 standalone 并采集逐算子基线，16 次 C512 `attn` 合计约 0.609 ms。
当前转置 logits 的相邻 query 线程按 64 个 FP32 的步长读 bias；尝试改变存储顺序，使相邻线程读连续数据。
仅在私有源码副本的 `nr_graph.cpp` bias packing 与 `attn.comp` 索引同步变更，全部 FP32 bias 原值重排，
保持 logits+bias 的操作数、FP16/FP8 边界、权重数值和归约顺序。没有改变矩阵乘加或有损选项。

| 布局 | 原逻辑 B[h,q,k] 的存储索引 | 目的 |
| --- | --- | --- |
| 原 | h×4096+q×64+k | 对照 |
| 完全转置 | h×4096+k×64+q | 相邻 query 连续 |
| 成对 | h×4096+floor(k/2)×128+q×2+k%2 | 同时保留每线程的两个相邻 bias |

两种重排的 65,536 个索引分别做完整 CPU 双射检查。候选只在成套私有 DLL/shader 中运行；
没有把未版本化的新 packing 放进生产 manifest。如将来保留此类布局，必须新增匹配的 shader/host 契约并验证混用拒绝。
