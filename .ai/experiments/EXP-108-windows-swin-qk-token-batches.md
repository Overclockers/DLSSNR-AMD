# EXP-108：C256 DS 的 Q/K 投影按 query 对分批

日期：2026-10-09（Asia/Hong_Kong）。结论：未保留（unproven）。
运行 `20261009-005048-lossless9070xt` 第 2/10 个假设；1 版实现，1 次追加确认。
起始主仓 `875f2c28789687b7c835fd2b63a8f885333a3045`；宿主 `6a8e322828d8d1f1ece67f87bd1bb1982d4464d1`。

## 假设与实现

joint Q/K 原先同时保存 4×4 个 FP32 累加片段；候选每次计算两个 query fragment，随即完成各自原有归一化，再处理下一对。每个结果的 K=0..15 次序及 norm 的 c/d/FMA 次序不变，Q/K 输出保存在原 qb/kreg，V 及后续计算不动。重排区域不写 LDS、不增加或删除同步点。不同于 EXP-020 扩张阶段与 EXP-088 输出投影阶段的分块。

disabled SPIR-V 精确复现基线，目标 FP32 与所有 packed 回读一致。driver .text 224512→224768 B、静态指令 32006→31987；VGPR 229→256，scratch 0→32 B，LDS 32768 B 不变。源码的分批未降低实际寄存器峰值，反而发生少量 spill。
