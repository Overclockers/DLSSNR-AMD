## 假设与实现

EXP-026 观察到 Swin 的低 L0/高 L2 命中，而领取本身占比较小。候选仅把每层零依赖的初始 ready IDs 从行优先重排为 4×4 空间块，希望缩短相邻窗口数据访问距离。item ID、依赖计数、消费者表、队列容量和发布/epoch 协议均不变；不修改 shader、数值权重、精度或单输出算术。每次建图将重排列表排序，与完整原始列表严格比较，证明 ID 集合、重数及零依赖资格一致。

分别从匹配宿主源码编译关闭/开启私有 DLL，复用已核验 adapter objects 和原编译定义；两版 ABI 检查通过。六段初始 item 数为 2960/740/190/190/760/2960，移动 2900/715/169/169/730/2900 个位置，排列断言全部通过。性能之前两版目标照片回读一致，全部 32 个性能/control/确认批次也一致。没有将排序/建图 CPU 时间计入稳态 GPU NR 区间。
