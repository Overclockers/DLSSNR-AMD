## 假设与实现

原 context 对两个输出通道片段依次完成各自四步 WMMA。候选以 key 片段为外层，交替更新两个独立累加器；各自 j=0..3 次序、概率、V、舍入、量化、store 和 barrier 均保留。不同于 EXP-097 的跨 query K/V 缓存，本项不延长 K/V 到下一 query，也不减少读取数量。

disabled SPIR-V 完全一致，FP32 整网 11,470,640 位模式和每批 packed 输出精确一致。VGPR 184、SGPR 59、LDS 9216 B、scratch 0 均不变；.text 26880 B，静态指令 3882→3874。末尾八条 context WMMA 从同一寄存器区间连续四步两组，变为 v[8:15]/v[0:7] 交错四次，机制已经实现。context-scheduling-proof.json 保存源级次序与原始 driver ISA 身份；不是全输入数值证明或收益预测。
