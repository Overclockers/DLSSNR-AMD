# EXP-032：同进程完整宿主双上下文对照

日期：2026-10-07。状态：**离线诊断夹具验证完成；没有生产优化**。
运行 `20261007-152904-schedule9070xt` 的 discovery，不计入 20 次优化额度。

## 问题与方法

EXP-030 的独立进程 ABBA 存在慢变漂移。检查同进程中预先初始化两个完整 NR 上下文，
在同一 D3D12 queue 上串行切换，能否降低同路径对照偏差。
从主仓 `windows/build/profile_host.cpp` 派生私有夹具；宿主源码、production DLL 未改。
每个 context 使用独立资产路径、Vulkan session、recording lease 和完整生产 shader 集合。
两个 context 的初始化/首次构建、预热和测量均顺序执行，没有并行 GPU 实验。

沿用两枚 D3D12 时间戳，范围仍从 D3D12 输入复制到输出复制，含整个 Vulkan 往返。
context 切换前收齐所有 tail fence、query 和 recording；复用 command allocator 前等待其完成。
每次切换后额外预热 10 帧，不计入结果。每个 block 最后重新执行一次并精确回读，位于时间戳之外。
序列 ID 单调递增；只有明确处于测量阶段的完成项写入 CSV。销毁发生在全部工作完成后。
这些检查覆盖工具的单遍静态测量路径，不代替宿主全面 ABI/history/replay 套件。

## 原路径对原路径结果

主仓基于 `3c4f0b7`，宿主 `3a88c92`；65 个宿主源与 76 个产物沿用本轮已核验身份。
RX 9070 XT / 26.8.1 (LLPC)，2258×1270 输入、2368×1280 工作尺寸，R11G11B10，
100% 模型尺寸、单次 NR、depth=3、无运动历史/SR/FG。两个上下文均加载独立保存的原始 shader。
每个 context 先预热 100 帧；ABBA×4 与反序 BAAB×4，每 block 测量 100 帧。

共 3,200 个测量帧、32 份逐 block packed 回读，全部与原始输出逐字节一致。
两次 CSV 均恰好包含 16×100 行，每个 block 的 context 标识匹配，时间戳顺序检查通过。
全部组都保留；没有排除首组 0.035883 ms，也没有将小均差称为噪声已经消失。
时钟、温度和持续后台负载未采样。**本研究没有证明相对原工具的噪声上限下降。**

两个上下文同时驻留会改变内存占用和分配，可能产生 context 相关偏差。
因此该工具可以筛选候选，但不能单独代替原独立生产路径的反序确认和完整验收。
