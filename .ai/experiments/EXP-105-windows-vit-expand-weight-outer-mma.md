# EXP-105：ViT 扩张按权重片段排列独立 MMA

## 假设与实现

仅在 gemmvact 的原 X×W^T 布局下，将 4×4 个独立输出片段的 MMA 嵌套改成权重片段在外、token 片段在内。每个 acc[i][j] 仍按 K=0,16,…,1008 的相同次序累加；输入、权重、pipeline bank、工作组分工、epilogue 与同步不变。区别于 EXP-054 的收缩层 W×X^T 转置和 EXP-016 的扩张 wave 分工/K chunk 改动。

关闭宏精确复现 baseline SPIR-V；16 个输出累加器各 64 次 K 片段的顺序检查通过。目标 FP32 与全部 packed 回读精确一致。驱动 .text 均为 13312 B、1720 条指令，VGPR157/SGPR20、零 LDS/scratch 均不变。18 处指令位置改变：独立 WMMA 相互之间及相对 s_wait_loadcnt 的位置改变；含操作数的完整指令多重集、每个目的累加器的 MMA 序列和去掉 MMA 后的指令序列均完全相同，证明文件 SHA256 `c0147b4642b796b6b94dd5ae21d445244b69516e0551e6c0c83156e3613d9aec`。当前算子诊断排名约 0.338 ms / 八次派发，不以历史 167 VGPR 数据替代当前 157 VGPR。
