## 假设与实现

目标逐层基线的 16 次 C512 attention 合计约 0.603 ms。两个 query 块读取同一份只读 K/V LDS；原型在原 QKV barrier 后加载八个 K 与八个 V 的 FP8 片段，跨 query 复用。与 EXP-023 的 ViT 全局 K/V 预取不同，本次消除 C512 query 循环中的重复共享内存读取。片段赋值保持类型及位值，每个 QK/PV MMA 的 K 次序、偏置、指数、precise FP32 sum、倒数、half/FP8 转换、地址、生产/复用屏障都不变。只修改独立 Windows shader 快照。

关闭宏后 SPIR-V 精确复现原基线。驱动 ISA 中循环体的 ds_load_2addr_b64 从 9 条变为 1 条，另有 8 条移到现有 barrier 后、循环前；按每 wave 的两个完整 query 块，动态读取指令数为 18→10。这只是指定路径的控制流计数，不是硬件等待周期或可直接换算的收益。VGPR 184、SGPR 59、LDS 9216 B、零 scratch 均未变；.text 同为 26880 B，静态指令 3882→3876，s_wait_dscnt 11→4。机制已实现，但完整路径结果表明减少 LDS 读取不足以改善此配置。源级生命周期与 ISA 循环核验保存为 reuse-proof.json（SHA-256 `b08f68c6c0c9325161cbd95ffa15b941adcf3307345373fa8b242d997c074469`）；ISA 汇总 `457caa8d9fb944140f5c195fa50254a1d8e92002d5665b10f1c13347b2d74b99`。目标 FP32 的 11,470,640 个 32 位值逐字节一致；所有宿主 packed 回读也一致。ABBA 与 BAAB 各 2400 个正式测量帧，两个同路径控制各 1600 个，共 8000 个正式帧；另有正确性短跑和统一预热后的 12 个回读帧，均不进入 A/B 汇总。
