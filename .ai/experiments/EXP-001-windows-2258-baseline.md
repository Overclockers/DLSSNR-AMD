# EXP-001：2258×1270 Windows 基线与 C256 边缘分支

日期：2026-10-06。状态：独立网络小幅收益；宿主构建与本地 GPU 验证通过，游戏验证待完成。

## 范围与身份

本仓库基础提交：`82560c4fbfaac347fc5e22c22025191402ae916b`。
使用新增原生 Windows benchmark 入口，复用 `nr_graph.cpp`、原生计划生成器和生产编译常量。
工具改动仅涉及构建、入口和计时显示，不改变推理算术。
MSVC 14.51.36231，C++17 /O2 /MT，glslang 16.5.0。
GPU 由 Vulkan 确认为 RX 9070 XT；驱动 26.8.1 为用户报告，完整驱动号未核验。

基线为宿主现有编译着色器的独立副本，保留该宿主的循环展开和 ViT 尾块驱动补丁。
候选基于宿主 vendored 源代码构建。构建工具已重新生成两个未修改的基线 SPIR-V，逐字节匹配后才生成候选。
完整资产 SHA-256 保存在生成的 `profile.json`，本机产物定位见忽略的本地记录。

## 输入与测量

- 源 2258×1270，原生计划工作尺寸 2368×1280，152 层合并为 123 次 dispatch。
- arena reuse 开，FP32 输入与输出，单次网络，合成梯度及仓库 2560×1440 验证输入图。
- 验证图经最近邻取样为目标尺寸、RGB/255、alpha=1，转换为 RGBA32F；这是离线图像输入，不是真实游戏捕获。
- 每轮 100 帧预热、200 帧计时，共享已预热的本地 pipeline cache。
- 用户退出游戏后运行，按基线/候选交错；不包含 SR、FG、跨 API 搬运或时间历史。
- Windows GPU 时钟/温度没有采样，不能排除所有频率与热状态漂移。
- 基准命令和构建方式见 [BENCHMARK.md](../../windows/build/BENCHMARK.md)。

## 选择的变更

仅 `fswinpds256`、`fswinpup256` 恢复 `NR_EDGE_BODIES=1`。
上游本来启用，宿主为减少启动编译时间而关闭；本实验属于宿主配置优化。
其他六个已关闭的内核保留宿主设置。既有专用分支不改变模型精度或运算定义，不是有损选项。

图像输入，逐内核计时开启：

| 1 | 10.890 | 10.723 |

| --- | --- | --- |
| 1 | 10.909 | 10.879 |
| 2 | 11.006 | 10.881 |

| 平均 | 10.990 | 10.893 |

最终平均节省 **0.097 ms，约 0.88%**。这是小幅、有限样本的离线结果，不宣称游戏 FPS 获益或统计显著性。
启用插桩时 C256 两段从约 0.85/0.66 ms 降至约 0.75/0.61 ms；其他内核及整帧波动会影响净收益。
恢复边缘专用体会增加首次驱动编译成本；缓存条件不同，未将首次构建耗时作为严格 A/B 数据。

## 排除或未采用的候选

| 配置 | 观测与处置 |
| --- | --- |
| 仅 C32 边缘分支 | 10.794/10.880 ms，邻近基线 10.849/10.822；无可靠收益 |
| C32 与输入/输出展开组减至 2 | 10.943/10.895 ms；无收益 |
| 宽 GEMM 增加宽访存/BDA | 10.761 ms，但目标 GEMM 段 0.650 vs 0.646 ms；不按整帧波动认定收益 |
| C128/C256 常驻内核扩大权重访存 | 11.163 ms，C128 明显变慢 |
| 输入/输出单 wave，K 保留寄存器 | 10.898/10.900 ms 且输出变化；不采用 |
| C256 展开与 V 阶段同时拆分 | 10.951 ms，上采样段变慢 |
| 输入/输出取消成对转换拆分 | 11.286 ms；变慢 |
| 宽 GEMM 交换矩阵角色 | 11.065 ms；无收益 |
| 六个常驻内核全开边缘分支 | 10.770 ms；进一步缩小为有明确收益的两个 C256 内核 |
| C256 边缘分支叠加展开拆分 | 10.629 ms，邻近仅边缘配置 10.624 ms；不增加额外开关 |
| C128 工作组 128/384 | 11.286/10.881 ms；缩小变慢，扩大未显示可靠改善 |
| C64 工作组 256 | 11.312 ms；变慢 |
| C256 工作组 128 | 10.886 ms vs 基线 10.897；差异太小，不采用 |

各候选测试顺序和缓存不同，表中孤立数字不可用于跨配置精确排序。
